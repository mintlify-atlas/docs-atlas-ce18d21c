Goose is a database migration tool for Go. It lets you manage your database schema by creating incremental SQL files or Go functions — and run them forward or backward as your application evolves.

Use it as a **CLI tool** for interactive migration management, or embed it as a **Go library** in your application for programmatic control.

## Supported databases

Goose works with all major relational databases out of the box:

| Database | Driver |
|---|---|
| PostgreSQL | `postgres` |
| MySQL / MariaDB | `mysql` |
| SQLite | `sqlite3` |
| ClickHouse | `clickhouse` |
| Microsoft SQL Server | `mssql` |
| Google Spanner | `spanner` |
| YDB | `ydb` |
| TiDB | `tidb` |
| Turso (libSQL) | `turso` |
| Amazon Redshift | `redshift` |
| StarRocks | `starrocks` |
| AWS Aurora DSQL | `dsql` |

## Get started in three steps

<Steps>
  <Step title="Install goose">
    ```bash
    go install github.com/pressly/goose/v3/cmd/goose@latest
    ```
  </Step>
  <Step title="Create your first migration">
    ```bash
    goose sqlite3 ./myapp.db create add_users_table sql
    ```
    Edit the generated file to add your SQL schema changes.
  </Step>
  <Step title="Apply migrations">
    ```bash
    goose sqlite3 ./myapp.db up
    ```
    Goose tracks which migrations have been applied and runs only the pending ones.
  </Step>
</Steps>

<Tip>
  Set `GOOSE_DRIVER` and `GOOSE_DBSTRING` environment variables (or a `.env` file) to avoid repeating the driver and connection string on every command.
</Tip>
